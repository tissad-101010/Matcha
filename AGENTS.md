# Règles de contribution

## Finalisation d'une tâche

- Une tâche ne peut être considérée comme terminée qu'après l'exécution réussie des tests et contrôles qualité pertinents.
- Dès qu'une tâche est terminée et validée, créer un commit dédié qui ne contient que les changements liés à cette tâche.
- Utiliser un sujet de commit précis et ajouter un corps détaillant les comportements livrés ainsi que les validations exécutées.
- Pousser immédiatement ce commit sur la branche distante courante.
- Ne jamais inclure dans le commit des modifications utilisateur ou des changements sans rapport avec la tâche.
- Si le commit ou le push échoue, signaler clairement l'échec et ne pas présenter la tâche comme publiée sur GitHub.
